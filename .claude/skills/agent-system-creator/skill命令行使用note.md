# skill 命令行具体使用： 
  claude CLI 有 -p/--print(打印即退出)、--add-dir(临时开放目录读取)、--plugin-dir(加载插件)等参数。结合你的需求(不安装、需要
  时终端一行调用),最可靠的方式如下。

  ✅ 方法 1:单行调用(推荐,每次一行命令)

  claude -p "请先读取 /Users/heweidong/Desktop/Agent-System Workflow/workflow/agent-system-creator/SKILL.md(含 references/ 
  子目录),严格按其 6阶段×12步 工作流执行,并按其输出格式交付。任务:帮我规划一个 AI 客服 Agent 系统"

  原理:技能未安装,所以不能自动触发;让 Claude 先读取技能文件并遵循它,效果等同。注意路径含空格,必须用引号包住。

  ✅ 方法 2:定义成短命令(以后一行搞定)

  把下面函数加进 ~/.zshrc(终端执行 open ~/.zshrc 或用 vim ~/.zshrc 编辑):

  #按需调用 agent-system-creator 技能(不安装)
  as-agent() {
    local SKILL="/Users/heweidong/Desktop/Agent-System Workflow/workflow/agent-system-creator"
    claude -p "先读取 ${SKILL}/SKILL.md 及其 references/ 目录,严格按其中定义的 6阶段×12步
  工作流执行,并按技能要求的输出格式交付。任务:$*"
  }

  然后 source ~/.zshrc,以后直接:

  as-agent 帮我规划一个 AI 客服 Agent 系统
  as-agent 设计一个多 Agent 系统架构,业务是某制造企业的工单自动化

  ✅ 方法 3:交互式会话中临时挂载(想在一个会话里连续用)

  cd "/Users/heweidong/Desktop/Agent-System Workflow/workflow"
  claude --add-dir "/Users/heweidong/Desktop/Agent-System Workflow/workflow/agent-system-creator"

  进入交互会话后再说一句「请遵循 agent-system-creator/SKILL.md 的工作流」,本次会话即可反复使用,退出后不残留安装。

##

  策略，skill：anget-system-creator是否也要进行同步的更新， 
  需要同步,但不是"全量复制",而是按变更层级做对应同步。核心要理解两者的关系:
     
  一、两者的定位(决定了同步策略)

  workflow/ 知识库 = 「源头档案」(Source of Truth,详细、含版本与案例)
  agent-system-creator skill = 「蒸馏后的可执行版」(精简、便携、渐进式披露)

  技能刻意不是知识库的副本——它用 <500 行的 SKILL.md 骨架 + 5 个 references 速查承载核心方法,所以:
  - 知识库改了一处,技能不一定每处都跟着改;
  - 但涉及技能所承载内容的变更,必须同步,否则技能会"过时"。

  二、对应关系表(改动哪个工作流文件 → 同步到哪个技能文件)

  针对你的例子——"修改了某个模块的实施策略":
  - 如果新增的是一条通用、可复用的实施策略 → 应该同步到 references/03-modules.md 对应模块段落;
  - 如果只是该模块某次项目的具体做法/参数 → 不需要同步,技能保持精简,执行时如需细节再查知识库。
