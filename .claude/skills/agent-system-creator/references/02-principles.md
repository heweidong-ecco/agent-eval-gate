# 参考 · 贯穿性设计原则(详情)

> 这些原则**不是独立步骤**,而是渗透到每一步决策的治理约束。执行任何步骤时都要对照自检。源:workflow 知识库 `03-横切设计原则/`。

## 一、安全、合规与伦理(注入:步骤 1–3)
- 数据隐私:识别 PII/企业机密,标注数据分级,设计脱敏与访问控制;传输加密。
- 模型安全:防提示注入/越狱/工具滥用;输入输出过滤;权限最小化(工具按 Agent 身份授权)。
- 合规审计:记录「谁、何时、为何」;满足金融/医疗可解释性与审计要求;不可篡改审计日志。
- 人在环中:关键/不可逆操作(转账、对外发邮件)必须人工确认;低置信度触发人工。
- 法律与 IP:输出合规过滤器(行业声明/格式/禁用词);第三方文档授权边界;防侵权/广告法/自动签约风险。

## 二、成本与 ROI(注入:步骤 2、3、9、11)
- Cost-aware 架构:成本分层 `缓存常见问答 → 本地小模型 → 云端大模型`。
- ROI 挂钩:节省人力/时间成本 vs 开发维护成本;FTE、CSAT、处理时间等 L3 指标与步骤 1 痛点基线挂钩。
- 成本异常监控:模型调用量突增、循环失控 token 爆炸 → 自动熔断与报警。

## 三、多 Agent 协作与人机协同(注入:步骤 1–2、4–6、10–11)
- Agent 间通信:消息协议、共享记忆黑板(Blackboard)、任务依赖图。
- 冲突仲裁:子 Agent 结论矛盾 → 投票 / 置信度加权 / 上报主控 Agent。
- 协作模式:串行流水线、并行扇出、主从调度。
- 人机三模式:辅助(Agent 建议,人决策)/ 增强(人机协作)/ 自动化(Agent 独立执行,人监督)。
- 培训与信任:内部试点、共创优化期、能力边界教育。
- 反馈闭环:显性通道(点赞/点踩/纠错)→ 回流持续优化与数据飞轮。

## 四、提示工程与模型版本管理(落地:步骤 4–6)
- 提示即代码:Prompt 模板化/参数化,纳入 Git,进行 A/B 测试。
- 模型回退与灰度:模型路由网关按租户/流量比例切流,秒级回滚。
- 评估数据集先行:步骤 4 就规划(标注意图、理想工具调用序列、标准答案)。

## 五、数据飞轮与主动学习(贯穿:步骤 1、9、11、12)
- 人类反馈强化回路:纠错/点赞点踩/人工复审结构化回流为训练样本。
- 半自动流水线:案例库 → 提示优化 → 知识库更新,周期蒸馏规则/Few-shot,推送人工审核。
- 记忆新鲜度:遗忘曲线/新鲜度衰减,避免过期知识固化。

## 六、可解释性与置信度透明(设计:4–6;观测:9–12)
- 输出决策链卡片:推理摘要、知识来源、工具调用参数与原因。
- 置信度评分:高于阈值自动执行,低于阈值请求人类确认。
- 可视化回溯:Trace 展示完整决策树,业务人员可自然语言查询「某次决策依据」。

## 七、灾难恢复与业务连续性(注入:步骤 3)
- 优雅降级链:主模型 → 备用模型(本地开源小模型)→ 静态规则/FAQ。
- 状态持久化与断点续传:长时间任务中间状态写入持久存储,恢复后从断点继续。
- 灾备演练:定期模拟核心依赖故障,记录 MTTR。

## 八、第三方依赖供应链风险管理(选型:2;实现:6;维护:12)
- 适配器抽象层:统一内部接口,便于切换底层模型/工具实现。
- 依赖监控:服务状态、API 弃用公告、计价变动 → 提前预警迁移。
- 兼容性回归:闭源 LLM 设定最低可用版本,定期回归测试。

## 九、用户心智模型与期望管理(需求:1;投放:10–11)
- 能力声明与边界引导:入口告知能做什么/不能做什么/哪些需人工核实。
- 渐进式暴露功能:先成熟能力,随熟练度解锁高阶任务。
- UI/UX 塑造认知:思考过程可视化、不确定时高亮提示,塑造「可靠、诚实」认知。

## 十、多租户与数据隔离(架构:3;编码:6)
- 全层隔离:记忆、向量库、任务队列、日志均逻辑/物理租户隔离,租户 ID 全链路透传。
- 受限检索:Agent 只能从授权知识分区召回。
- 租户级注入防护:防范租户级别的指令越界攻击。

## 落地自检清单(每步对照)
- [ ] 数据是否分级并脱敏? [ ] 注入过滤与权限最小化是否生效? [ ] 高影响操作有人工确认?
- [ ] 成本分层与 ROI 挂钩? [ ] 反馈是否回流? [ ] 决策链与置信度是否产出?
- [ ] 降级链与断点续传就绪并演练? [ ] 适配器层就绪? [ ] 能力边界已声明? [ ] 租户隔离覆盖所有存储层?
