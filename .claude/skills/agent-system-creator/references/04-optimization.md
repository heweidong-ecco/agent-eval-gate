# 参考 · 持续优化策略与量化指标

> 系统上线后的进化策略。每一步优化都要用**对比数据证明**,且不损害 L2/L3 质量。源:workflow 知识库 `06-持续优化策略/`。

## 1. 数据飞轮与主动学习
- 闭环:`用户/人工反馈 → 案例结构化 → 半自动提炼(规则/Few-shot)→ 评估回归 → 上线`。
- 人类反馈强化回路:纠错/点赞点踩/人工复审 → 训练样本。
- 半自动流水线:案例库 → 提示优化 → 知识库更新;产物须过**人工审核队列**。
- 记忆新鲜度:遗忘曲线/新鲜度衰减。
- 指标:反馈回流率、评估集规模/更新频率、评估准确率趋势、人工介入率趋势、优化周期。

## 2. 稳定性与鲁棒性
- 容错加固:超时→重试/降级→熔断/自愈;优雅降级链(主→备用→FAQ)。
- 混沌工程常态化:定期故障注入(网络延迟/服务宕机/模型超时/DB 故障);输出《故障场景应对手册》。
- 灾备:状态持久化 + 断点续传;定期演练记录 MTTR。
- 异常检测自动化:日志/Trace 聚类发现新型错误模式。
- 指标:可用性(SLA≥99.9%)、MTTR(下降)、自愈成功率(提升)、混沌演练覆盖度(100%)、优化前后对比(延迟/吞吐/错误率)。

## 3. 性能优化
- 定位先行:用全链路 Trace 归因「慢在模型/检索/工具/编排哪一环」。
- 分层优化(高收益→低收益):缓存优先 → 模型优化(分层路由/Prompt 精简/输出长度)→ 检索优化(索引/embedding 缓存)→ 编排优化(并行/批处理)→ 基础设施(扩容/连接池/限流背压)。
- 流式与体验:流式响应降 TTFT;长任务进度可见。
- 指标:P50/P95/P99、TTFT、QPS、资源占用、缓存命中率。
- 纪律:性能优化必须同步验证 L2/L3 不劣化。

## 4. 成本优化
- 成本构成:`模型调用(Token×单价)+ 检索 + 基础设施 + 人工`,先核算再优化。
- 最大杠杆:**模型分层路由**(简单→小模型,复杂→大模型);缓存复用;上下文压缩;循环失控熔断。
- 模型替换评估:更便宜/更快模型在评估集离线对比后切换。
- 指标:单任务 Token、单请求成本、大模型调用占比、缓存命中率、单位业务产出成本(FTE 等价)。
- 纪律:每项成本优化同步跑评估集回归,保证准确率/完成率不降。

## 5. 版本迭代与发布策略
- 版本管理:语义化版本;模型/Prompt/评估集/代码同库、可回滚。
- 评估门禁:变更自动跑评估集,低于阈值阻断发布。
- 金丝雀/灰度:按租户或流量百分比,新旧同屏对比 L1/L2/L3,无劣化放量。
- 秒级回滚:模型/Prompt 路由网关一键切回;回滚可记录可审计。
- 指标:变更上线周期、评估门禁通过率、灰度对比时长、回滚时长(秒级)、线上事故数。

## 量化指标速查(L1/L2/L3)

| 层 | 指标 | 参考基线 |
|----|------|----------|
| L1 系统 | 延迟 P50/P95/P99、QPS、错误率、资源 | 压测基线;P99 达标 |
| L2 代理 | 任务完成率、工具调用准确率、自愈触发率、平均步数 | 评估集回归;低于阈值阻断 |
| L3 业务 | 人工介入率、CSAT、处理时间缩短%、FTE 节省、成本节省 | 对标步骤 1 痛点基线 |

> 三层联动预警:技术指标劣化(L1/L2)→ 预警业务指标受损(L3)。
