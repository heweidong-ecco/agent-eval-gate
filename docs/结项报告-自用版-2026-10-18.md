## 5. 如何复现一轮 live 回归(零猜测)

```bash
# 0) 语料:正文在仓外(不在任何 git 仓)
#    ~/Desktop/Product-external/eval-corpus/fastapi_rag_eval_corpus-20261018.jsonl
python3 tools/seed_eval_corpus.py \
  --corpus ~/Desktop/Product-external/eval-corpus/fastapi_rag_eval_corpus-20261018.jsonl \
  --manifest eval/corpus/manifest.json --dry-run        # 先校验 sha256

# 1) 起被测(隔离库 + 放宽会话预算;含能力探针)
export EVAL_SUT_FASTAPI_API_KEY=...
EVAL_SUT_DB=rag_eval_20261018 EVAL_SUT_SESSION_TOKEN_LIMIT=200000 \
  tools/sut-harness/run_sut.sh

# 2) 灌语料
python3 tools/seed_eval_corpus.py \
  --corpus ~/Desktop/Product-external/eval-corpus/fastapi_rag_eval_corpus-20261018.jsonl \
  --manifest eval/corpus/manifest.json --base-url http://127.0.0.1:8000

# 3) 跑评测
set -a; . eval/runs/.sut-harness.env; set +a
export SSL_CERT_FILE=/etc/ssl/cert.pem
.venv/bin/python -m eval_gate run --evals eval/fastapi_rag_golden.evals.json --report-dir eval/runs
```

> ⚠️ 灌语料前确认目标是**隔离库**;不要灌生产 `rag_db`(它已有 345 行,含其它项目数据)。
