## 8. 阅读纪律

- **历史文档按过去时读**:`reports/`、`plans/`、`复盘/`、`decisions/` 里写的"当前/下一步",
  只对**当时**成立;当前事实以 `CLAUDE.md`、`ROADMAP.md`、`结项报告` 为准。
- **架构变化**:同时更新 `总纲.md §1.1` 与 `arch/README.md`。
- **新增文档**:更新本索引;如果它有"标准/规矩",同时登记进 `../CLAUDE.md` 或 `../README.md` 的入口。
