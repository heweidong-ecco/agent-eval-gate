# DEC-025 · 开源文档面与许可证

- 状态:**已实施**(2026-10-18)
- 类型:仓库文档面 / 许可证 / 安全报告渠道
- 关联:`docs/结项报告-自用版-2026-10-18.md` · `DEC-024`(结项范围与语料存放)

## 1. 背景

本仓是 **Public**。结项前对照了三类标准:

1. **GitHub 社区健康文件**(README / LICENSE / CONTRIBUTING / SECURITY / CODE_OF_CONDUCT / SUPPORT
   + issue/PR 模板 + CHANGELOG);
2. **Standard Readme**(标题 / 描述 / 目录 / 安装 / 用法 / 贡献 / 许可证);
3. **同类评测项目的实际结构**
   (promptfoo · openai/evals · deepeval · inspect_ai:普遍有 `docs/` + `examples/` + CONTRIBUTING + PR 模板)。

审计结果:本仓缺 **LICENSE / CONTRIBUTING / SECURITY / SUPPORT / CHANGELOG / FAQ / docs 索引 /
examples / issue+PR 模板**,且 `github/` 下的模板文档**不在 `.github/`**,GitHub 不会展示。

## 2. 决策

### 2.1 许可证:**MIT**

| 方案 | 评价 |
|---|---|
| **MIT(选定)** | 最短、最通用;参考的同类项目多数用 MIT(promptfoo / openai/evals / inspect_ai)。与"自用先行、以后外化"一致 |
| Apache-2.0 | 有显式专利授权,但文本更长、合规成本更高;deepeval 用它 |
| 暂不授权(proprietary) | 公开仓默认"保留所有权利" ⇒ 别人不能合法复用,与 Public 的目的冲突 |

**代价**:MIT 不提供专利授权与商标条款;若将来需要,替换 `LICENSE` + `pyproject.toml` 两处即可,
但**已发布的版本无法追改**(旧 tag 仍是旧许可证)。

### 2.2 安全报告:**GitHub 私密漏洞报告**

- 渠道:仓库 **Security → Report a vulnerability**(`SECURITY.md` 写明);
- **不公开邮箱**:单人维护,公开邮箱会带来垃圾与社工面;
- 代价:依赖 GitHub 的私密报告功能(该仓已启用);若将来迁出 GitHub,需要在 `SECURITY.md` 换渠道。

### 2.3 行为准则:**暂不采用**

- 单人维护、无社区治理流程,采用 Contributor Covenant 会引入"谁来执行/如何申诉"的空承诺;
- **明确记为"不适用(当前)"**,不是遗忘;`CONTRIBUTING.md §7` 写清基本要求与保留关闭权;
- **触发条件**:开放外部维护者 / 接受外部 PR 成为常态时,**先补正式 CoC**。

### 2.4 FAQ 放哪:**`docs/FAQ.md`**,不放根级 `FAQ.md`

- GitHub 的社区健康文件清单里**没有 FAQ**;参考项目也把 FAQ 放在 docs 站 / Troubleshooting;
- FAQ 内容**只收本仓真实踩过的坑**(密钥 401 / 能力探针 / 生产库污染 / 语料复现 / 429 / exit code / 校准)。

### 2.5 模板位置:**`.github/`**

- `github/issue-模板-labels.md` 与 `github/pr-模板-评审.md` 是**说明文档**,GitHub 不识别;
- 本次新增 `.github/ISSUE_TEMPLATE/*.yml` 与 `.github/PULL_REQUEST_TEMPLATE.md`,
  内容按上面的说明文档改写为 GitHub 可展示的格式;旧说明文档保留(作为依据)。

## 3. 本次范围

**做(P0+P1)**:LICENSE · SECURITY · SUPPORT · CONTRIBUTING · CHANGELOG · FAQ · CLI 参考 ·
docs 索引 · examples · issue/PR 模板 · README 目录/贡献/许可证段 · pyproject 元数据 · 架构图。

**暂缓(P2)**:`CODE_OF_CONDUCT.md`(见 §2.3)· `CITATION.cff`(非学术项目)·
`GOVERNANCE.md` / `CODEOWNERS`(单人)· README badges · 独立文档站。

## 5. 认下的代价

- ⚠️ **许可证是法律选择**:本次按推荐默认 MIT;若你实际要 Apache-2.0 或 proprietary,
  必须**在发布前**改,发布后旧 tag 无法追改;
- ⚠️ **CoC 暂缺**:外部贡献者多起来时会被 GitHub 社区健康检查标黄,须按触发条件补;
- ⚠️ **文档面补齐 ≠ 功能闭环**:`U2 发版 CI` 仍未接入(见 `DEC-024`)。
