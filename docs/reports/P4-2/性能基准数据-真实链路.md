## 3. 可比性规则(什么情况下**不可比**)

✅ **可比**:同一被测版本、同一用例集、同一 `_env` 下的两版**门**之间的差(如"门 v0.3.0 vs v0.4.0 的逐 case 开销")。

⚠️ **不可比 / 必须先声明**:

1. **跨机器**:`_env.cpu_count` 或 `platform` 不同 ⇒ 绝对延迟不可直接比;
2. **跨被测版本**:被测 commit 变了就不是同一系统(本基线绑定 `f2dad78`);
3. **与 P4-1 的桩基线比**:那份是注入延迟,不是被测性能;
4. **单轮 vs 多轮**:本基线 `fastapi-rag` 池了 3 轮,而其中**一轮明显偏慢**(§2 警告)⇒
   **不要**把池化 p50 当作"这个被测的响应时间";
5. **n<20 的高分位**:最近秩法下 p95/p99 退化为 max,不具统计意义;
6. **不同并发度**:本基线一律串行(并发=1),与任何并发数字不可比。
