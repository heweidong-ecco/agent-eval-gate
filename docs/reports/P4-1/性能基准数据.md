## 3. 怎么比(可比性规则)

✅ **可比**:同一 `dataset.cases` 与同一 `params` 下的两版 **门**——例如
"v0.3.0 的门自身开销 0.051 ms/case vs v0.4.0 的 X ms/case"(比的是**门**的演进)。

⚠️ **不可比 / 需注明**:
1. **跨机器**:`env` 不同(核数、OS)时吞吐不可直接比 —— 先看 `env.cpu_count` 是否一致;
2. **桩 vs 真实**:`inject_sut_ms` 是**注入休眠**,不是被测性能。
   要谈被测性能,必须读 `eval/runs/<run_id>.trace.jsonl` 的 span,不能用本文件;
3. **不同 `n` / 不同并发集**:`per_case_ms` 的 p95/p99 是**小样本最近秩法**(n=3 时 p99 == max),
   样本太少时不要解读高分位;
4. **A/B 文件是合成抖动**:其 `warning` 字段已声明"不代表真实模型噪声",**不得**当作模型质量基线。

## 4. 百分位口径(改了就不比了)

`app/eval_gate/bench.py::percentile` = **最近秩法**:`index = ceil(q/100 * n) - 1`,钳制到 `[0, n-1]`。
小样本下它比插值法更保守(不会给出观测中不存在的值)。改这个口径 = **前后不可比**,须走 DEC。
