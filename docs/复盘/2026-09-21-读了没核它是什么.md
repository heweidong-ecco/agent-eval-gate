# 复盘 · 2026-09-21 · 「我拿到一个输出/数字,但**没核它数的是什么**」 —— 一天七处

- 日期:2026-09-21 · 触发:业务方说「落复盘」(本条起于 E5,查证时**又连出七处**)
- 结论:**不是七个小疏忽,是同一个动作** —— 读结果时**跳过了一个问题**。

## 1. 七处实例(**全部发生在同一天**,全部**在造成影响前**被拦住)

| # | 我读的是什么 | 实际数的是什么 | 若照原样写下去会怎样 |
|---|---|---|---|
| 1 | `cmd \| tail -4; echo $?` | **`tail` 的**退出码,不是 `cmd` 的 | 把 `exit 1` 报成 `exit 0`(端到端验证"通过") |
| 2 | `grep "f6sENslSr"`(**手打**的式) | 实际是 `f6sENslRQ` ⇒ **静默返回空** | 下结论"指纹不在文件里",去**修一个不存在的悬空引用** |
| 3 | `gh pr view 21` | 跑在 **eval-gate 的 cwd** ⇒ 解析成**另一个仓**的 PR #21 | 把 **2026-09-12** 的状态报成"避坑库今天的 PR" |
| 4 | `grep -l … -c … \| wc -l` | **`wc -l` 数的是行数**(每文件一行),**不是命中数** | 报"**87 个文件含私钥**"(实际 **0**) |
| 5 | `git merge-base --is-ancestor <分支> main` | 对 **squash 合并**恒为假(分支提交**不是** main 的祖先) | 报"**9 个分支全部未合并**"(实际 11 个的 PR 都已合) |
| 6 | `git cat-file -e "main:$非ASCII路径"` | git 给非 ASCII 路径**加了引号转义** ⇒ 拼出来的 ref **找不到** | 报"**main 上没有这个文件**"(实际**都在**) |
| 7 | `grep -l "状态:**待签核" docs/decisions/*.md` | 匹配的是「**文件里任何地方**出现过这四个字」——包括**变更历史里的旧状态** | 报"**4 份待签核**"(实际 **2 份**;`DEC-015`/`DEC-017` 早已签核,只是历史里记着"建立(状态:待签核)") |

## 2. 共同形状:**拿到结果就往下走,没问"它是什么"**

七处的命令、工具、场景**全不一样**,但动作是同一个:

> ### 我读了一个**符号**(`0` / `1` / `87` / `空` / `false` / `找不到`),
> ### 而**没有核它代表什么**。

**⚠️ 三种输出最容易被误读成"核实通过"** —— 因为它们**同时兼容两种相反的原因**:

| 输出 | 可能是① | 可能是② |
|---|---|---|
| **空** / **0** | 真的没有 | **我找错了**(#2 #6) |
| **恒假** / **恒空** | 判据说"不成立" | **判据在这种前提下不适用**(#5) |
| **一个数字** | 就是我要的数 | **数的是别的东西**(#4) |

## 3. 与既有复盘的关系(同族,不是新病)

- `A5`(**验证的假象**):「我做了验证动作」≠「这个验证**真的能失败**」;
- `docs/复盘/2026-09-15-收尾批次-过程错误.md` **E3/E4**:判据取了"看起来对"的东西;
- **本日的** `2026-09-21-门修复-实现先行.md`:「**跑了、有红的、后来绿了**」≠「红绿通过」;
- **本日的** `2026-09-21-凭据串凭记忆写给用户.md`:连**核实用的那个值**都是手写的。

⇒ 本条是它们**在"读结果"这一步上的合并形态**:**判决词、判据值、判据前提,三者都可以是错的,而错法都表现为"一个看起来正常的输出"。**

## 4. 落地判据(可照做)

> ### 读任何结果前,先问三句:
> 1. **这条输出是"谁的"?** —— 管道后 `$?` 是**最后一段**的;`gh` 认 **cwd** 的仓;
> 2. **这个数字数的是什么?** —— 行数?命中数?文件数?**逐条读一遍产生它的命令**;
> 3. **我这个判据在这种前提下成立吗?** —— squash 合并 ⇒ `is-ancestor` 失效;
>    非 ASCII 路径 ⇒ 引号转义;机器可读输出 ⇒ 可能返回**空 JSON 而非空字符串**。

**配套两条**:
- **拿"空/0/恒假"当结论前,先验产生它的命令本身**(拿一个**已知有**的样本试一次 —— 若已知样本也返回空,那是命令坏了,不是东西不在);
- **把工具换成"会自己说清前提"的那种** —— 本次把 `--is-ancestor` 换成 **`gh pr list --state merged`**
  (它直接回答"这个分支的 PR 合没合"),判据就从"祖先关系"变成"**事实**"。

## 5. 本条的代价与收益(如实)

- **代价**:七处**每一处都返工了一次**(重跑命令 / 重做判断);
- **收益**:七处**都在落盘之前**被拦住 —— 尤其 **#3 #4 #5 #6 #7**,

  ⇒ **拦住它们的是"再核一遍"这个动作本身**,不是"我记得"。
