## 二、教训(可复用的判断规则)

1. **"全中 / 全不中"优先当成工具坏了。** 一个探测器若把所有样本都判为同一类,它**更可能是坏的**,而不是"世界就是这样"。**先在已知答案的样本上跑它**。
2. **改文件的判据不是"命令成功",是"内容对了"。** 退出码 0 只能说明没报错。必须**复核结构**:语法检查、列数、关键串是否在位。
   定位待改处要用**内容锚**(唯一串),**不要用切分**。
3. **记录不是事实源。** 一手 = 代码 / 决策文件 / 产物;**二手 = ROADMAP / 锚点 / 摘要 / 我的记忆**。
   用二手立计划前先核一手;核完**把来源写进清单**(可复核)。
4. **测试的密闭性判据 = "把本地产物藏起来还能过"。** 依赖 `.gitignore` 掉的本地文件 = **只在本地通过**。
   (同日实证:`tests/test_archive_evidence.py` 初版 glob 本地 trace ⇒ **本地绿、CI 红 `StopIteration`**。)
5. **共同的形状:这四次都"不报错"。** 退出 0、测试绿、文档通顺 —— 与本项目一贯主题(**静默失败**)同源。
   ⇒ **"没报错"不是"对了"**;要另外找一个**独立判据**去证。
